# Studio Aura Design

Landing page responsiva desenvolvida como projeto prático de Front-end, com foco em experiência visual, responsividade, interatividade e animações.

## 🌐 Ver projeto online

https://roxanerx.github.io/studio-aura/

## 📌 Sobre o projeto

O Studio Aura Design foi desenvolvido durante meus estudos de Desenvolvimento Front-end, aplicando na prática conhecimentos de HTML5, CSS3 e JavaScript.

O projeto apresenta uma interface moderna e responsiva, com recursos visuais e interativos pensados para proporcionar uma experiência mais dinâmica ao usuário.

## 🚀 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- GSAP — GreenSock Animation Platform
- ScrollTrigger
- Git
- GitHub
- GitHub Pages

## ✨ Funcionalidades

- Layout responsivo
- Animações de interface
- Animações controladas pelo scroll
- Efeito parallax
- Integração de vídeos
- Galeria de projetos
- Validação de formulário
- Elementos visuais e interativos
- Organização visual baseada em Design System

## 🤖 Inteligência Artificial no desenvolvimento

Durante o desenvolvimento, utilizei Inteligência Artificial como ferramenta de apoio ao processo.

Também trabalhei com skills especializadas, como **GSAP Skill** e **Taste Skill**, para orientar melhor o agente de IA, aprimorar animações, refinar a interface e elevar a qualidade visual do projeto.

A IA foi utilizada como suporte ao desenvolvimento, enquanto os conceitos, estrutura e funcionamento do projeto foram estudados e aplicados ao longo das aulas.
